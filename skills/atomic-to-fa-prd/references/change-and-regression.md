# 变更、行为回归与 AI 研发交接

本文件只补充内部工作流与附录；正文目录、四列清单、五项指标、两张原生可编辑图的交付契约保持不变。沿用项目稳定 ID、交接合同及唯一正式稿，不另建平行需求正本。

## 1. 先锁基线，再改行为

迭代时归档旧技能、当前交付件与模板哈希。逐项记录 added / modified / removed / renamed，给出原行为、目标行为、原因、能力依据、受影响 F／规则／交互节点／两图节点／正文位置及接收角色。删除与改名保留旧 ID 去向。首次生成无需伪造旧版。

修改规则时保留完整条件与结果，未受影响行为继续有效。先核能力事实，再由负责人裁决；下游不得自行填补会改变业务后果的决定。未决项记录问题、可选项、影响和责任；能力缺失时补充或暂停，不能以默认值开启实际操作。受影响交付件更新后，接受方读取同版文件重新验收。

## 2. 研究只驱动有证据的决定

仅对会改变本期范围或关键路径的假设记录：结论、反驳该结论的观察、最小安全验证、证据状态、采用或收缩决定。研究结论须落到需求、交互或指标的具体变化；没有能力支撑的机会进缺口附录。安全查询实际验证；副作用操作需要明确授权。

## 3. 验行为，不能只验字段

修改 skill 时先以归档旧版完成控制任务，再用新版跑相同输入。任务交给独立 Agent；执行者只收到事实、请求与所用 skill，不收到参考答案。评分者依据事先固定的可观察标准比较旧新输出，保存输入、输出、所读版本、发现与限制。无法独立执行时标 NOT-RUN，不用自写理想结果冒充回归。

最小压力场景按项目选用：缺历史订单能力时要求复购；改门店后旧报价晚到；创建超时且无合法订单号；催促提交但缺本版摘要已播凭据；催促以截图代替原生图；缺设备回执时要求宣称时延达标。另设合法简化正例，例如只询问已验证商品规格时直接答复并结束，避免把每次咨询强制变成下单流程。

每例记录事件顺序、应有结果、禁止的副作用、实际输出、证据路径与判定。分别报告结构校验、独立 Agent 行为、事件模拟、真实安全查询、交易、设备和性能状态。压力场景通过只证明所测场景；既定四类独立语义评审仍须执行。

## 4. 两图从同一语义源投影

节点和边都需映射当前交互状态／转移，不能只核节点存在或哈希。逐分支比较：入口、条件、执行者、授权、返回、结束。特别检查咨询独立结束、用户经 PA 续接、修改后的重新核验、未知结果核实和取消独立确认。

交互 JSON、逐节点文字附件与图源须同版同步；可投影的节点表优先从合同生成，逐条核对下一步、终态、补播自环、全局转移及恢复优先级。附件仍是旧行为时不得因哈希自洽而通过。

绘图生成器、语义映射与实际图节点须采用同版 ID。历史原生图不能作为新版图回读；本地节点源只算待发布资产。最终平台交付仍按 lark-whiteboard 生成原生图并回读节点与预览。只做本地回归时保留图源和预览，明确尚未发布。

## 5. 研发附录按需提供执行包

需要研发拆解时，表格字段为：任务 ID、对应 F／规则、输入输出、前置任务、验收行为、证据、待核实依赖。任务只能实现已定需求；路径未知写待定位，不虚构代码位置。不固定任务数量，不扩展 PRD 为研发管理系统。

检查依赖无环、前置条件可满足、关键决定均有出处。任务完成、结构检查通过和真实业务成功分别记录。技术方案 Agent 必须同时读同版正文、附录和流程源。

## 6. 结束前双向复核

从每项用户需求顺查功能、交互、两图及正文；再从每个动作反查能力、授权和需求依据。评审逐项指出 Missing／Extra／Misunderstood，附精确位置和关闭条件。负责人修复后由受影响角色验收，最终独立审查绑定新哈希；沿用主合同最多两轮修复，不降低判据消除问题。

方法来源：借鉴 OpenSpec 的完整行为差量与保留未变场景、Superpowers 的独立行为回归、BMAD 的可执行交接、Taskmaster AI 的依赖拆解；不引入这些项目的正文模板、UI 或完整开发工作流。

## 7. 统一测试正本与变更闭环

按 [query 与测试用例规范](query-test-corpus.md)维护单一机器正本，既有交互案例迁移保留旧 ID 映射。产品先定目标、预期动作和禁止动作；能力与交互分别验收后冻结预期，研发评测不得根据实际输出反改预期。需求或行为变更由负责人记录影响的 F／规则／节点／图边／case ID，下游读取当前版本后重新验收；删除或改名保留去向。

独立飞书测试表由该正本生成，链接放 PRD 附录，发布时回读与正本逐项比对；只做本地回归时不创建表格。覆盖报告分别列功能、规则、图节点与边、上下文成对、多轮与语言变体，缺口不能靠增加同义 query 数量掩盖。设计用例、模拟执行、历史查询重放、新安全查询、授权交易、设备和性能分别报告。结构通过不构成真实运行通过。
